# 📊 Monthly Expense Tracker

## 📌 Project Overview
The Monthly Expense Tracker is an interactive Excel-based data analytics project designed to track and analyze monthly income and expenses.

It helps users understand their spending patterns, monitor their financial balance, and gain meaningful financial insights through an interactive dashboard.

## 🎯 Project Objectives
- Track monthly income and expenses.
- Organize transactions into different categories.
- Identify major expense categories.
- Analyze spending by payment mode.
- Calculate total income, expenses, and remaining balance.
- Build an interactive Excel dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Tables
- Data Validation
- SUMIF and COUNTA
- PivotTables
- PivotCharts
- Slicers
- Interactive Dashboard

## 📂 Dataset Information
- Total Transactions: 20
- Period: November 1–20, 2026
- Transaction Types: Income and Expense
- Payment Modes: UPI, Cash, Net Banking

## 📈 Key Results

| Metric | Value |
|---|---:|
| Total Income | ₹35,000 |
| Total Expenses | ₹17,699 |
| Remaining Balance | ₹17,301 |

## 🔍 Key Findings
- Rent was the highest expense category at ₹6,000.
- UPI was the highest expense payment mode at ₹8,299.
- The dashboard provides interactive filtering through slicers.

## 📊 Dashboard Features
- Financial KPI Cards
- Category-wise Expense Analysis
- Payment Mode Analysis
- Interactive Category and Type Slicers
